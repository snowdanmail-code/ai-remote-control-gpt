# Roadmap после v2.14.28

1. **v2.14.29: реальный источник состояния.** Сопоставить координаты и последовательности настоящих кадров из записей 1win, получить фактический Android package name и размер JPEG на смартфоне, проверить роли мест/кнопок, стадию, время, карты, ставки; строго отделять наблюдения от авторизованных фактов.
2. **v2.14.30: игровая логика.** Без выдумывания equity построить независимую оценку диапазонов соперников и источник verified equity, связать с `VerifiedLocalPokerStrategy` и памятью после раздачи.
3. **v2.14.31: действие и подтверждение.** Завершить авторизованный маршрут `AutonomousObservation -> decision -> guarded gesture -> independent post-action proof`; никаких повторов при неизвестном результате; STOP из любого состояния.
4. **До APK:** проверка ограничений API/SDK, отдельный репозиторий, Gradle/JUnit, Android эмулятор не обязателен: реальный телефон для установки и разрешений; тест качества на записанных настоящих кадрах, регистратор ошибок, проверка правил сторонней платформы.
5. **APK:** собрать через GitHub Actions, проверить установку на Android, отчёт SHA-256, сохранять старые релизы.

Все игровые фишки по текущему описанию пользователя виртуальные без ввода/вывода средств. Сборка только после завершения исходников по утверждённому порядку.

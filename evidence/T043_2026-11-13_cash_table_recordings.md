# T043 — фактические наблюдения интерфейса 1win (два видео, 13.11.2026)

Источник: видеозаписи пользователя `Screen_Recording_20261113_030125.mp4` и `Screen_Recording_20261113_030422.mp4`, обе `1080 × 2340` в портретной ориентации. Длительность ~135 и ~156 секунд. Видео использованы только для анализа интерфейса; этот документ не является доказательством полноты Android OCR или разрешением на ставки.

## Визуальная ориентация

- За шестиместным столом именно **наш игрок всегда в нижнем слоте** независимо от первоначального выбора места; интерфейс разворачивается относительно игрока.
- Остальные пять экранных позиций: верхняя, верхняя левая, верхняя правая, нижняя левая, нижняя правая. Не следует связывать конкретный номер физического места с верхом/низом без проверки после поворота.
- Карты нашего игрока у нижнего слота; общие карты по центру. Признаки ставки и подписи к игрокам могут быть поверх поля.
- Величины стека/банка/текущего колла необходимо различать; значения на старом кадре нельзя считать ещё действительными после изменения интерфейса.

## Временные ориентиры на этих видео

| Запись/время | Видимое состояние | Важное следствие |
|---|---|---|
| Запись 1 ~24 с | Кнопки вскрытия/скрытия карт после раздачи | Не путать с кнопками игрового действия |
| Запись 1 ~44 с | Тёмная полоса предварительных решений: Фолд / Колл / Уравнять любую | Это предварительные опции, не подтверждённый активный ход |
| Запись 1 ~48 с | Цветная полоса: Фолд / Колл / Рейз | Обычные кнопки активного хода; колл включает сумму |
| Запись 1 ~64 с | Цветная полоса при флопе | Состояние кнопок зависит от фазы и допустимых решений |
| Запись 2 ~93 с | Цветные Фолд / Чек / Ставка | В отличие от колла, чек не требует суммы |
| Запись 2 ~96 с | Смена на панель выбора размера: Мин / 1/2 / Банк / Макс / Подтвердить сумму, справа вертикальный ползунок | «Ставка» открывает **редактор размера**, а не означает отправленную ставку |
| Запись 2 ~98 с | Панель скрыта, ставка отображена у нашего игрока и банк увеличился | Реальное исполнение должно проверяться по следующему кадру/подтверждению |
| Запись 2 ~112 с | Фолд / Колл / Рейз | Названия действий динамические |

## Реализованный в PR №8 диагностический контракт

- `OneWinRecordedCashTableUi.kt`: различает `HERO_TURN`, `PREACTION`, `BET_SIZE_EDITOR`, `SHOWDOWN_CONTROLS`, `UNKNOWN`.
- `OneWinRecordedTableUiConsistency`: только после двух согласованных OCR-наблюдений одного окна подтверждается режим интерфейса.
- `OneWinPortraitHeroSeat`: допускает вывод нижнего слота из измеренной калибровки, а не из имени/номера игрока.
- `OnDeviceOneWinRecordedTableUi.kt`: отдельный локальный русско-английский OCR для экранных элементов стола, без отправки касаний/покупок/ставок.
- `OneWinRecordedCashTableUiTest.kt`: регрессия для стандартной полосы, редактора ставки, предварительных решений, вскрытия карт и поворота места.

**Не реализовано как подтверждённая функция:** принятие ставок по этим наблюдениям, вычисление обязательной суммы рейза, подтверждение списания после ставки и проверка всей связки на конкретном Samsung. Из двух видео нельзя достоверно вывести все состояния, правила изменения размеров или точные активные области для любой версии приложения.

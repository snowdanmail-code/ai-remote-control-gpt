## Правила выполнения

- Один чекпойнт — одна или несколько небольших технических правок + 2–5 отрицательных тестов + понятный GitHub коммит. Отвечать по фактам, не заявлять реализации «всё работает» до устройства.
- Не собирать большой массив личных данных: никнейм используется только локально. `seat_N` — позиция экрана, не постоянный ID человека.
- OCR-сигналы, исчезнувшие рубашки и фишки являются наблюдениями. Нет независимого provenance — нет verified opponent action или разрешения игрового жеста.
- Нельзя суммировать уже отображённый pot и фишки около мест второй раз.
- При смене таблицы, обрыве сети, STOP, неизвестном результате действия или долгом ответе ChatGPT — сброс/отмена, не повторять денежные касания.
- Без подключения внешнего game-state provider невозможно автоматически доказать подписанный table/turn/seat; в этом случае честно отмечать этап как BLOCKED и продолжать другие доступные работы.
- Для подписки ChatGPT: использовать только официально разрешённый OAuth token с отдельным scope; не подменять его ключом API и не скрейпить веб-сессию.

## Прогресс этого захода

- **01**: `T050VerifiedTableIdentity.kt` + тесты; обязательная связка по независимо проверенному `tableId`. При первой проверке очищаем старую сеансовую OCR-память и повторяем обход; при новом столе в том же Android-окне сбрасываем посадку и прекращаем старую сессию GPT.
- **02**: `verifiedActorKey` обновляется лишь после проверенного `T047SeatActorProof` и достоверно стабильного actor key; конфликт стирает связь. `T050VerifiedSeatProfileBinding.kt` + тесты исключает FOLD/LEFT/UNKNOWN и дубли; GPT получает `seat_N` только при проверенном actor→seat map. Старые `opponent_1/2` по порядку списка больше не подставляются.
- **03**: `T043GptDecisionContract` больше не удаляет подтверждённое описание участников ради соблюдения 1600-символьного ограничения. При невозможности уместить достоверную картину раздачи не отправляет неверно сокращённый запрос.
- **04**: `T050TransientBadgePulseTracker`, `OnDeviceRawSeatBadgeDiagnostics` и тесты: отслеживание 2 совпадающих raw кадров примерно 300 мс, одновременных мест, изменения интенсивности на фоне белого аватара. `OnDeviceAutomaticOcr` больше не декодирует тяжелый T048 JPEG внутри общей FrameStore блокировки; повторно удостоверяет кадр после декодирования.
- **05**: `evidence/T050_video_reference_labels.json`, `tools/t050_video_replay_check.py`, `tests/test_t050_video_reference.py` — истинные примеры из видео, проверка разделения рейза слева и фолда сверху около 42 с и фолда справа около 48 с, локально измеренные пропорции ярких/зелёных пикселей. Это **не** готовый JSON калибровки Samsung.
- **CI**: #528 и #532 были зелёными ДО новых изменений. Первые новые проверки выявили одну ошибку экранирования Kotlin в тесте `T043GptDecisionContractTest`, она исправлена коммитом `47b796b`. Последующие задания #563 (повторный attempt 2) завершились через 2–3 секунды **без назначенного runner и без шагов** (`runner_id=0`, `steps=[]`). Причина в инфраструктуре GitHub Actions/учётной записи не установлена; отсутствие запуска тестов нельзя считать ни PASS, ни исходной компиляционной ошибкой.
- **Дальше**: нужен реальный зелёный CI на HEAD, затем медленный и быстрый видеореплей, подписанный source of truth для hand/turn/seat, авторизованный телефон, полноценный effect receipt. Не обещать автономную игру без этих доказательств.

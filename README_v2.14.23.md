# AI Remote Control GPT v2.14.23 — единый аналитический контур соперников

**Тип релиза: пакет исходников; APK НЕ собран.** Основа v2.14.22. Предыдущие версии не переписаны.

## Добавлено

- `LiveOpponentAwareness.kt`: независимый, работающий в памяти сборщик положительных подтверждённых действий соперников в текущей раздаче: улица, действие, подтверждённая ситуация «перед ставкой», верифицированная идентичность. Требует двух отдельных кадров, проверяет возраст, порядок, окно, эпоху и идентификаторы стола и раздачи.
- Синхронная защита от повторов одного `actionKey`, противоречивых подтверждений, повторного использования кадров и событий из другой раздачи. Неизвестные значения остаются `null`: отсутствие наблюдения **не доказывает** отсутствие VPIP, PFR, фолда, шоудауна или действия.
- `OnDeviceOpponentAwareness`: Android-адаптер к **прежнему** `PostHandLearner` и SQLite. Читает накопленную статистику + наблюдения текущей раздачи. Текущие события не записывает на диск до подтверждённого завершения.
- `OnDeviceVerifiedHandCompletion`: данные соперников передаются через существующий `VerifiedHandCompletionGate` с независимым подтверждением **двух активных** и **двух терминальных** кадров; отдельного маршрута «сохранить сейчас» не добавлено.
- При STOP, смене захвата/окна/раздачи очищается только временное состояние. Уже сохранённая SQLite-история не стирается.
- Поправка статистики: неизвестный fold-vs-bet результат не учитывается как подтверждённая возможность (в прошлом счётчик возможностей увеличивался на один лишь факт ставки). Малую выборку профиль явно обозначает ненадёжной.
- В локальный журнал добавлены типизированные события `OPPONENT_OBSERVATION_REJECTED`, `OPPONENT_CONTEXT_INVALIDATED`, `OPPONENT_HAND_STORAGE_FAILED`. Никакие имена игроков, ID рук, токены, скриншоты и OCR-тексты в журнал не включаются. Офлайн-анализатор `tools/analyze_incident_report.py` их понимает.
- Новые JVM-сценарии, сценарий интеграции с gate, 4 Android JUnit-кейса для будущего CI, 7 Python source-contract тестов. Имя артефакта GitHub Actions обновлено, код версии увеличен до 57.

## Техническая граница доверия

Это **не доказательство работы на настоящем игровом столе**. Независимый источник ID стола, ID раздачи, личности соперника и подтверждённых действий по-прежнему не подключён. `VerifiedOpponentHandStart`, `ConfirmedOpponentAction` и `VerifiedHandBoundaryFrame` — строгие входные контракты, а не сам распознаватель.

Неофициальное OCR, координата места игрока или имя приложения сами по себе не считаются надёжной личностью игрока. Профиль на разных столах или сессиях допускается только при подлинном стабильном ключе с областью действия (например, подтверждённый session-scoped key); анонимное `seat-N` между раздачами **никогда** не объединяется.

Изменения не ослабляют STOP и не дают разрешения на касания. Полноценная компиляция Android и установка APK в этой среде не выполнялись. Для реальных автоматических касаний требуется разрешённый оператором платформы тестовый режим.

## Продолжение

Приоритет следующего этапа — достоверный независимый источник наблюдений: проверка качества распознавания ID стола/раздачи, положения и действия игроков на наборе реальных, размеченных кадров, измерение ложных распознаваний. Без этого имеющиеся математические, стратегические и обучающие модули остаются диагностическими.

# AI Remote Control GPT — реестр разработки и контроля перед APK

Контрольная точка: **v2.14.21**. Целевая среда — Android с оригинальным игровым приложением, только разрешённый тестовый режим с условными фишками, без денежных ставок или обхода ограничений платформы.

## Уже присутствует в исходниках (тесты JVM, НЕ испытание на Android)

- **Захват Android:** MediaProjection; периодическое локальное распознавание карт и OCR; очистка данных при STOP.
- **Контекст окна:** привязка к поколению активного окна, проверка свежести и происхождения кадра; НЕ доказательство конкретного стола.
- **Автономный контур:** один запрос действия на подтверждённый ход; ожидание независимого подтверждения; блокировка повторного жеста.
- **Служба касаний:** AccessibilityService.dispatchGesture с проверками и STOP. Реальные касания в 1win НЕ проверялись.
- **Статистика соперников:** SQLite-контракт сохранения только подтверждённых завершённых раздач; реальный поставщик идентификаторов не подключён.
- **v2.14.21:** локальный ограниченный журнал инцидентов, связь события с фазой/действием/допустимыми действиями/числовыми показаниями, отчёт JSON по явной команде пользователя, офлайн-разбор Python, повторная проверка таймера после решения, lock-free сигнал STOP.

## Нерешённые компоненты перед полным автономным тестом

| Модуль | Что требуется | Условие приёмки |
| --- | --- | --- |
| Понимание стола и раздачи | Независимый достоверный источник конкретного стола/раздачи, очереди хода и подтверждённого действия | Ни одна неизвестная раздача не разрешает действие; отсутствие источника не подменяется догадками |
| Компьютерное зрение | Распознавание карт, дилерских анимаций, фаз, мест, ставок, таймера и кнопок; ROI-зоны и контроль изменений | Набор записанных и размеченных кадров/видеофрагментов, метрики ошибок и ложных срабатываний |
| Покерная математика | Оценка 7-карточных комбинаций, кикеров, split/tie, пот-оддсов, стеков, рейзов, side pots, equity | Тесты с известными правильными исходами, пограничные случаи и независимые сравнения |
| Стратегия | Версионируемая стратегия, математические ограничения, проверка контекста и допустимых действий | Стратегия не выдаёт команду при недостоверных данных, не подменяет результаты расчётов догадками |
| ИИ-связь | Официальный поддерживаемый способ вызова модели, лимиты, таймауты, локальное защищённое хранение ключей, выход из аккаунта | Ошибки сети/авторизации ведут в safe-stop, токены не попадают в журналы, нет предположения о включённом API в Plus |
| Память соперников | Идентичность сессий и игроков, достаточная выборка, локальная долговременная история | Анонимные места не склеиваются между столами; подтверждённые данные не дублируются |
| Android-устойчивость | Приоритет STOP, разрешения, блокировка экрана, повторный захват, поворот, ограничения фона, экранные панели | Инструментальные тесты на смартфоне; стабильность на длительных сессиях |
| Отчёт о сбоях | Проверить регистрацию/ротацию на устройстве и экспорт через ACTION_CREATE_DOCUMENT | Любой инцидент воспроизводимо сводится в отчёт; сохранение не ломает STOP |
| Правила среды | Выяснить, допускает ли оператор приложения внешнюю автоматизацию в выбранном тестовом режиме | Если нет явного разрешения — никаких автоматических касаний |

## Фиксация ошибок в будущих испытаниях

1. Оператор запускает приложение, разрешает нужные системные службы и наблюдает за тестовым сеансом.
2. Android автоматически записывает события `CAPTURE_*`, `OCR_*`, `DECISION_*`, `COMMAND_*`, `OPERATOR_STOP`. Хранятся только типизированные поля, а не JPEG, OCR-строки, аккаунты, имена игроков или API-ключи.
3. После эксперимента нажать **«ЭКСПОРТ ОТЧЁТА ОБ ОШИБКАХ (ВРУЧНУЮ)»** и сохранить `incident-report-v2.14.21.json`.
4. Прикрепить JSON к чату для анализа и следующей итерации кода или разобрать на компьютере: `python3 tools/analyze_incident_report.py incident-report-v2.14.21.json -o triage.md`.
5. При каждом исправлении хранить прежний ZIP и SHA-256 отдельно, не перезаписывая проверенную версию.

Экспорт НЕ является автоматической отправкой разработчику/в ChatGPT: такого канала в приложении пока нет и он должен быть добавлен только при подтверждённом разрешении пользователя с отдельной безопасной авторизацией. В сети приложение ничего не публикует.

## Что ещё НЕ проверено

Отсутствует Android SDK и полноценная Gradle-сборка в текущей среде. Соответственно здесь **не проводились** `assembleDebug`, установка APK, реальный захват/жест/STOP на смартфоне, доступ к ChatGPT API и испытания в 1win. Локальные JVM и Python проверки служат предварительным фильтром, не подтверждают готовность автоплеера.

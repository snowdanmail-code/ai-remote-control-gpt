# AI Remote Control GPT v2.14.36 — исправление диагностики ChatGPT OAuth

**База:** исходники v2.14.35, оригинальное Android-приложение, без эмуляции.

## Причина обращения
На Android 16 (Samsung SM-A266M) браузер показал «Вход передан приложению» после OAuth callback `127.0.0.1`, но проверка облачного ИИ завершилась общим `IllegalStateException`. Это сообщение **не доказывает**, что сохранены access/refresh-токены, и не позволяет узнать фактический HTTP-статус. Точная причина не установлена без диагностики на устройстве.

## Реально внесённые изменения

- Страница loopback callback больше не объявляет успешный вход до проверки ID token и сохранения credentials.
- При успешном callback пользователь видит статус «Браузер вернул код. Проверяю обмен токенов…»; приложение отдельно показывает завершение/ошибку.
- Пока выполняется OAuth, кнопка тестирования ИИ сообщает `AUTH_IN_PROGRESS`, не посылая преждевременный запрос.
- Код диагностики разделяет этапы `AUTH_CALLBACK`, `AUTH_TOKEN`, `AUTH_IDENTITY`, `AUTH_STORE`, `CLOUD_SESSION`, `CLOUD_MODELS`, `CLOUD_RESPONSE`.
- Неизвестный `IllegalStateException` теперь показывается с этапом, а не одной бесполезной общей надписью.
- Не сохраняются и не отображаются токены, секреты, URL callback или текст ответа HTTP, содержащий приватные данные; HTTP-статусы выводятся как безопасные числовые коды (401/403/429/520 и т.д.).
- Различаются отсутствие сеанса, отсутствие разрешения использовать ChatGPT-план, отсутствие моделей, обрыв SSE, проблемы обновления токенов.
- Кнопка «СОСТОЯНИЕ CHATGPT» показывает раздельно сеанс, предыдущий результат авторизации и предыдущую проверку модели.
- Для потокового Responses API установлен заголовок `Accept: text/event-stream`.
- Обновлены `versionCode=70`, `versionName=2.14.36-chatgpt-connection-diagnostics`; старые исходники и защита STOP сохранены.

## Как проверить на устройстве

1. Сначала в установленной **v2.14.35** нажмите **«СОСТОЯНИЕ CHATGPT»** и отправьте только текст или снимок статуса (без URL с OAuth `code`/`state`, токенов или паролей). Он уже сообщает о наличии/отсутствии сохранённого профиля.
2. После выпуска и установки исправленного APK v2.14.36: «ВОЙТИ ЧЕРЕЗ CHATGPT» → завершить согласие в браузере → вернуться в приложение → дождаться статуса `AUTH_OK` либо точного `AUTH_*` кода.
3. Затем «ПРОВЕРИТЬ ПОДКЛЮЧЕНИЕ ОБЛАЧНОГО ИИ» → дождаться `CLOUD_OK` или `CLOUD_*` кода.
4. Если код `CLOUD_MODELS_HTTP_520` или `CLOUD_RESPONSE_HTTP_520`, это серверная ошибка, **не** доказательство ошибки пароля. Сообщения об HTTP 520 в потоке SIWC в октябре 2026 уже опубликованы, но у данного пользователя статус ещё не измерен.
5. Не нажимать «ВЫЙТИ ИЗ CHATGPT» без необходимости; удаление данных приложения может уничтожить локально сохранённую сессию и журнал.

## Ограничения тестов

- `python -m unittest discover -s tools -p 'test_*.py' -q` — **256/256**.
- `tools/run_chatgpt_oauth_tests.sh` — 30 старых проверок OAuth + 25 новых проверок диагностических сообщений, Python-контракты — 15.
- Компиляция реального `ChatGptCloudBridge.kt` с Kotlin/JVM и минимальными **заглушками Android/JSON** — успешно; это **не** Android SDK-компиляция и не полноценная работа приложения.
- Полный Kotlin/JVM-набор был запущен, но не завершился за время ожидания; результат не заявлен как успешный.
- Android APK, фактическая авторизация OAuth, сетевой ответ OpenAI на смартфоне не проверены в этой среде. Продукционная сборка и установка требуются отдельно.

## Сборка через ChatGPT Work / GitHub Actions

Загрузить архив исходников v2.14.36 в Work. Построить debug APK `./gradlew :app:assembleDebug`, проверить `assembleDebug`, манифест, подписку и SHA-256, выполнить запуск на Android 16. При обновлении установленного APK сохранить **тот же ключ подписи**, иначе Android заблокирует обновление поверх без переустановки. Не просить пользователя стирать данные или удалять приложение без сохранения нужных сведений.

Официальные документы: https://developers.openai.com/siwc/token-sharing-open-source/sign-in и https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference.

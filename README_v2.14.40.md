# AI Remote Control GPT — v2.14.40 OAuth token transport fix (source-only)

## Причина исправления

На Samsung Android 16 в установленной v2.14.39 после успешной HTTPS-проверки `auth.openai.com/.well-known/jwks.json` (200) и `api.openai.com/v1/models` (401 без токена) OAuth-код не обменивается на токены: `AUTH_TOKEN_DNS_FAILURE`. Код v2.14.39 выполнял **дополнительный** `InetAddress.getAllByName("auth.openai.com")` непосредственно перед отправкой POST. Этот независимый DNS-запрос мог завершиться ошибкой, запрещая даже попытку рабочей HTTPS-транзакции. Это дефект логики, но без трассировки устройства нельзя исключить и реальный DNS-сбой при HTTPS.

## Изменения

1. Удалена повторная обязательная `ChatGptDnsAdmission.preflight()` и устаревший вспомогательный класс.
2. DNS/HTTPS доступность диагностируется **одним настоящим HTTPS GET**, а не отдельным предварительным `InetAddress.getAllByName`.
3. Добавлен `ChatGptTokenConnect.openBeforeBody`: до отправки OAuth-данных выполняется HTTPS `connect()`. Однократный повтор допускается лишь если это соединение упало на `UnknownHostException` до отправки тела. Остальные исключения не повторяются.
4. Для OAuth POST установлен `setFixedLengthStreamingMode`; тело запроса записывается ровно один раз после успешного соединения. Ответ или тайм-аут **никогда** не вызывают повторного отправления кода.
5. Нет новых кнопок. Сохранены системный Chrome, 2FA, PKCE/state/nonce, строгая подпись ID-токена и STOP.
6. В CI ссылка на базовый APK обновлена до подписанного v2.14.39 (`versionCode=73`). Кандидат — `versionCode=74`, пакет `com.example.airemote.dev` и прежний сертификат SHA-256 `511567f44b5e527b8b388d0ea2a66ad30725a856ef76670c027b88c25007cd2c`.

## Ограничения

- Данный ZIP — **исходники, не APK**. Невозможно подтвердить исправление ошибки на Starlink из офлайн-тестов.
- Нет разрешения отключать 2FA или встраивать пароли/токены/коды в APK.
- Требуется полноценный Gradle `:app:testDebugUnitTest` и `:app:assembleDebug` в Work, проверка подписи кандидата, затем один контрольный вход на реальном телефоне.
- Вход ChatGPT не даёт права на автоматические касания в 1win. OCR/STOP/локальная стратегия сохранены, но не признаны полноценной живой автономной игрой.
- Возможны иные причины DNS после этого исправления; прежде чем менять сеть или OAuth наугад, нужны обезличенные сведения о конкретном сбое HTTPS из приложения, без повторных скриншотов и установок ради кнопки диагностики.

## QA

- Python: выполнить `python -m unittest discover -s tools -p 'test_*.py' -q`.
- Kotlin/JVM: `bash tools/run_jvm_tests.sh`.
- Независимая компиляция облачного модуля с тестовыми заглушками Android выполнена, но она не заменяет Android Gradle build.

## Изменения

Сохранены Custom Tab с браузерной заменой, callback600сек, одна попытка через Android active Network после DNS-сбоя до передачи тела, автоматическая проверка модели после входа и сохранение причины AUTH_* при последующем NO_SESSION. Внешний обмен остаётся HTTPS OpenAI. Отдельного InetAddress.getAllByName, нового DNS/прокси, ослабления TLS и повторной отправки тела OAuth после его записи нет.

Архив частично возвращал старый OAuth-код. Сохранены защиты проверенной v2.14.40: единый допуск входа/запроса, отмена позднего сохранения после выхода, сериализация rotating refresh, отдельная блокировка хранилища, общий строгий OIDC/JWKS/RS256/issuer/aud/azp/expiry/nonce verifier и безопасные коды ошибок. Автопроверка выполняется после завершения входа и проверки поколения сеанса; CLOUD_OK требует response.completed с непустым ответом. Прежние PREFS/alias Android Keystore сохранены.

Сохранены исправления AndroidX, nullable Kotlin/OCR_ENGINE_ERROR и тестовых загрузчиков/аргументов консенсуса. Набор и порядок26 кнопок совпали с архивом; новых кнопок нет. Файлы STOP, ограничений оператора, диспетчера и Accessibility не изменены. Захват/OCR/стратегия/память/математика/журналы сохранены.

Упаковке тестового APK мешал исчезающий файл синхронизации .rsync-tmp; сборку перенесли в изолированный каталог через init-script и повторили команды. Для медленной эмуляции настроены таймауты инструментального ADB; таймауты приложения этим не менялись. Init-script и ошибочные логи приложены.

Подготовлены и скомпилированы пять Android-тестов; выполнено 5, не прошли 1. На первом полном прогоне прошли четыре проверки: неверный callback, ошибки/таймаут, Keystore с заменой refresh и завершённый SSE. Custom Tab не получил подставной callback за120сек. Диагностика выявила системный ANR «System UI isn't responding»; причинную связь с таймаутом и отсутствие дефекта в коде входа этим не доказать. KVM недоступен. API35 не завершил загрузку в контрольное ожидание604сек. API29 выдал BOOT_COMPLETED, но затем PackageManager/ADB работали нестабильно: `Unknown API Level`, затем `Can't find service: package`; прямой запуск через ADB дал частичный результат, но не успешный полный набор. Журналы сохранены. Это не успешный runtime-тест и не диагноз ошибки APK. После переноса изменяемого диска эмулятора за пределы синхронизации и повторной компиляции тестового APK следующая установка тестового пакета превысила180сек; повторный набор не запустился. Это ограничение среды, успешным результатом не считается. Для завершения этой части нужен стабильный Android-эмулятор с аппаратным ускорением либо отдельное доступное тестовое устройство.

## Пределы подтверждения

Реальный OAuth/2FA, права подписки и ответ OpenAI не проверялись. Пароли, 2FA и пользовательские токены не использовались. Компиляция, callback-страница или тестовый ответ не объявляются успешным подключением ChatGPT. Автоматическая проверка в коде требует реального завершённого ответа; фактический результат с аккаунтом владельца пока неизвестен.

Установка и работа на Samsung SM-A266M Android16, AccessibilityService, MediaProjection и игровой цикл не подтверждены. minSdk29, targetSdk35, ARM64 и16КБ-проверки подтверждают структуру пакета, а не физическое испытание Android16. Совпадение package/certificate и повышение versionCode проверены для обновления; данные телефона не считывались и не удалялись. Исходный README описывает состояние до этой сборки; актуален этот отчёт.

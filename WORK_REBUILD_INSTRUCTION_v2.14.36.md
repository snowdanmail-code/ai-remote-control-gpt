# Задание для ChatGPT Work: исправить и собрать APK v2.14.36

Прикреплён ZIP с **реальными исходниками v2.14.36**, основанными на v2.14.35. На Samsung SM-A266M Android 16 браузер отдаёт callback `127.0.0.1`, но тест облачного ИИ в установленной v2.14.35 показал `IllegalStateException`. В v2.14.36 добавлено разделение диагностики. Используй исходники, не начинай проект с нуля.

1. Выполни Android Gradle `:app:assembleDebug`, исправь фактические ошибки (не отключай OAuth, STOP и проверки касаний).
2. Проверь новый код `ChatGptCloudBridge.kt`, `ChatGptCloudDiagnostics.kt`, `MainActivity.kt`, разрешение `INTERNET`, Android 16.
3. Если доступен Android эмулятор, проверь интерфейс. Публичную авторизацию реального пользователя не симулируй, не вводи его пароль или OAuth-код самостоятельно.
4. Для обновления поверх существующей установки **важна та же signing certificate**. Если Work ранее собирал APK, получи исходный signing key или объясни необходимость переустановки с потерей локальных данных; не стирай данные без согласия.
5. Предоставь фактически созданный APK, прямую ссылку, SHA-256, лог сборки, тесты и ошибки. Не выдавай ZIP с исходниками за APK.
6. После установки оператор выполнит вход и отправит безопасный `AUTH_*`/`CLOUD_*` код, если тест не пройдёт. Токены, пароли, callback `code` и `state` передавать нельзя.

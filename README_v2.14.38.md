# AI Remote Control GPT v2.14.38 — единый Android release candidate

## Для владельца

Это **исходники для одной контрольной Android-сборки**, не готовый APK. Новая v2.14.38 НЕ устанавливалась на Samsung SM-A266M и НЕ тестировалась через Starlink. **Никакой необходимости сейчас обновлять телефон нет.** Предыдущие версии v2.14.35–v2.14.37 не изменены.

### Исправлено в самих исходниках

1. В `MainActivity.kt` оставлено четыре основных рабочих действия: войти через ChatGPT, проверить ответ модели, захватить экран, включить проверенный AI-контроллер. Постоянный STOP доступен снаружи прокрутки. Все остальные кнопки, калибровка, экспорт ошибок, просмотр кадров и повторное разрешение после STOP действительно расположены в **закрытом по умолчанию** разделе «Настройки и отчёт».
2. В `ChatGptCloudBridge.startSignIn` ДО открытия системного Chrome теперь автоматически выполняются два запроса **из Android-приложения**: открытый JWKS на `auth.openai.com` и открытый каталог моделей на `api.openai.com` (ожидаемые 401/403 также означают доступность API). Проблемы DNS, TLS, connect, timeout или HTTP 5xx предотвращают новый вход с 2FA. Preflight проверяет только сеть, **не подтверждает действительность разрешений или успешный обмен токенов**.
3. Обработка OAuth остаётся в штатном внешнем браузере; сохраняются PKCE, state, nonce, 2FA на стороне OpenAI и защищённое хранение токенов. Одноразовые OAuth-коды не повторяются после сетевого сбоя.
4. Повышен `versionCode` до **72**, текущий source `versionName` — `2.14.38-release-candidate`; при сборке debug добавляется `-test`. Отдельное debug-имя пакета `.dev` НЕ менялось, так как настоящие старые APK имеют `com.example.airemote.dev`.
5. `.github/workflows/android.yml` теперь одна точка облачной сборки: Android Gradle tests → Gradle assembleDebug → `apksigner` + `aapt` + `verify_android_upgrade.py` → SHA-256 → публикация APK. Если старый ключ подписи или данные APK отсутствуют, публикация **запрещена**.
6. `tools/verify_android_upgrade.py` делает fail-closed сравнение подписанного APK с метаданными предыдущей установленной версии: пакет, отпечаток сертификата и повышенный versionCode. Самого старого APK в источниках нет, но его проверенная метаинформация включена (`tools/reference_prior_apk_v2.14.36.json`).

### Найдены реальные прежние APK

Прочитаны архивные APK, уже загруженные в библиотеку пользователя:

- `AI-Remote-Control-GPT-v2.14.35-CHATGPT-CLOUD-debug.apk`: package `com.example.airemote.dev`, versionCode 69, APK signer v2 SHA-256 `511567f44b5e527b8b388d0ea2a66ad30725a856ef76670c027b88c25007cd2c`.
- `AI-Remote-Control-GPT-v2.14.36-ChatGPT-Connection-Fix.apk`: тот же package, versionCode 70, **тот же сертификат**. ZIP CRC проверен для обоих файлов. Отпечаток извлечён из блока подписи APK; полноценную криптографическую проверку корректности подписи обязательно повторит Android `apksigner` в CI.
- SHA-256 старого v2.14.36 APK: `13cdf388dc13dd8ab9f9c2297a565531f9e21a45d6501fea1e7c2845566b7a2f`.

**Ограничение:** из старого APK нельзя извлечь закрытый ключ подписи. Work/CI должен использовать сохранённый прежний keystore, если он существует в прежней среде сборки. Иначе обновление поверх старой установки с сохранением данных нельзя обещать.

### Проверки, реально выполненные в среде

- Python: **277 из 277**.
- Kotlin/JVM отдельно: OAuth — **30 из 30**; облачные ошибки — **25 из 25**; новая проверка сети перед входом — **16 из 16**.
- Новый CloudBridge Kotlin с тестовыми заглушками Android: **компиляция прошла**. Это не сборка Android.
- Полный прежний большой Kotlin/JVM-набор был остановлен лимитом времени и **не заявлен пройденным**.
- Android SDK, Gradle и доступ к серверам загрузки Android SDK/Gradle в этой среде **отсутствуют**. Реального `assembleDebug`, Android JUnit, `apksigner`, установки и ответа реальной облачной модели **не проводилось**.

### Чтобы получить устанавливаемый APK

Следуйте `WORK_BUILD_HANDOFF_v2.14.38.md`. **Не публиковать и не передавать пользователю APK**, пока он реально не построен и не прошёл сравнение сертификата с v2.14.36. Если signing-keystore недоступен, остановиться и объяснить ограничение — **не требовать удаления приложения и не подменять ключ**.

Нет в архиве: личных токенов OpenAI, паролей, кодов 2FA, приватных ключей, самих старых APK и оригинальных экранных записей.

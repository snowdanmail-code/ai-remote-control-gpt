# ТЗ №042: безопасность подключения проверенного источника, 22.10.2026

Base: `57d368bc276a962bcfbae2c25654ef8ff8616141`. Только рабочая ветка PR №2.

## Исправлено
- Разрыв в разрешении запуска: `OnDeviceAuthorizedPlayerFeed.install` подключал источник, но `startIfAuthorized` принимал только `OnDeviceAuthorizedPlayerCycle.providerConnected`. Теперь обе версии **проверенного** входа имеют единый контроль маршрута и не допускают одновременного подключения двух источников.
- После глобального STOP отключаются обе регистрации источников и сбрасывается проверенная привязка хода; старый callback не остаётся активным.
- Регистрация callback-поставщика запрещена во время захвата и без аппаратного режима STOP оператора.
- Пока предыдущая команда ждёт доказанного эффекта, callback-канал не может передать новый ход.
- Добавлены сценарии JVM и проверки исходной интеграции.

## Чего это НЕ означает
Реальный источник состояния игры 1win **не появился**. Допуск по этой архитектуре по-прежнему требует независимого полномасштабного подтверждения карт, банка, легальных действий, текущего хода, разрешения на автоматизацию и фактического результата. Эти изменения нельзя использовать для притворного подтверждения OCR или Android callback. Не запускать денежные игры, платный режим или непроверенный APK.

## Проверка
Новые и существующие тесты должны пройти в PR CI. Отдельно обязательны Android 16 instrumentation, реальный Samsung, действующая подпись и проверка разрешённости автоматизации. Этот коммит **не создаёт APK**.

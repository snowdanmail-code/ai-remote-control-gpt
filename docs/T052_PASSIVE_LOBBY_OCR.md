# T052 — Только OCR столов, без нажатий

Причина исправления: на Samsung Code97 было «Русский OCR ещё не запускался»
и ноль распознанных столов при активном захвате. В Code97 распознавание
кэш-лобби вызывалось только при автоматическом выборе стола.

## Сценарий на Samsung

1. Установить подписанную тестовую сборку Code98 только после зелёного CI и проверки подписи.
2. В AI Remote Control оставить включённым захват экрана и не включать автоигру.
3. Нажать «1WIN — ТОЛЬКО OCR СТОЛОВ (БЕЗ НАЖАТИЙ)».
4. Перейти в 1win → «Кэш-Игры» и оставить список столов видимым.
5. Вернуться в AI Remote Control и нажать «1WIN — РЕЗУЛЬТАТ OCR СТОЛОВ».
6. Прислать снимок строки: число строк OCR и число подтверждённых столов.
7. Нажать «1WIN — ОСТАНОВИТЬ OCR СТОЛОВ» или глобальный STOP.

Тест **не** нажимает элементы интерфейса 1win, не выбирает стол,
не переходит к бай-ину, не отправляет ставки. Он использует существующий
локальный Tesseract rus+eng и независимое совпадение двух OCR-кадров.
При несовпадении или потере внешнего окна число подтверждённых столов
может остаться нулевым; это диагностический результат, а не повод
ослаблять проверку происхождения данных.

Автоматический выбор блокируется, пока включён пассивный OCR.
Все сообщения отображаются только локально.

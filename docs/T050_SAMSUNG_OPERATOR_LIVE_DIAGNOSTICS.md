# T050 — живой журнал ИИ на Samsung, тестовая сборка Code97

Рабочая ветка: `feature/t043-gpt-decision-contract`, PR #8.
Режим: инженерный тест; реальная автономная игра и подписанный источник состояния раздачи **не подтверждены**.

## Что видно оператору

Основной экран Android — раздел **ЖИВОЙ ЖУРНАЛ ИИ**, обновление раз в ~400 мс:
- STOP (остановка/разрешение), статус захвата и число полученных кадров;
- состояние AUTO и его конкретное объяснение отказа;
- состояние запросов GPT и ответ: кандидат получен или причина отказа;
- проверка достоверного хода;
- стадии поиска стола, посадки, обхода профилей и изучения соперников;
- лента из последних восьми событий: OCR, смена окна, команда, её отклонение/передача, подтверждение эффекта, ошибка.

Кнопка **ПОКАЗЫВАТЬ МИНИ-ЖУРНАЛ ПОВЕРХ ИГРЫ** включает компактное окно на фоне
1win через уже разрешённую службу Accessibility. Оно не реагирует на касания,
не включает игру, не заменяет STOP. По умолчанию выключено. При STOP, потере
достоверного окна или захвата мини-журнал скрывается (основной журнал остаётся).

Только внутренние коды событий и локальные состояния. В экспортируемый журнал
не попадают скриншоты, имена игроков, сырой OCR, токены ChatGPT или модельный
ответ. На экране отображаются только внутренние диагностические состояния,
заведомо не являющиеся самостоятельным доказательством выполнения жеста.
`GESTURE_COMPLETED_OS` не означает, что ход в игре был подтверждён.

## Порядок проверки на Samsung

1. Установить совместимую signed Code97 APK после успешных CI и проверки
   сертификата **того же** установленного приложения; не создавать новый ключ.
2. Открыть приложение. Убедиться: STOP активен, AUTO ничего не отправляет.
3. Включить службу Accessibility в системных настройках Android.
4. В приложении включить «ПОКАЗЫВАТЬ МИНИ-ЖУРНАЛ ПОВЕРХ ИГРЫ».
5. Разрешить новую сессию оператором и начать MediaProjection-захват.
6. Открыть 1win и наблюдать мини-журнал; для подробного списка вернуться
   в приложение. Проверить переходы состояний, OCR ошибки, таймауты,
   STOP/потерю окна и прерывание захвата.
7. При непонятном поведении нажать STOP и экспортировать
   **ОТЧЁТ ОБ ОШИБКАХ** через кнопку в расширенных настройках.
   Отправка файла выполняется пользователем вручную, не автоматически.
8. Не считать несколько успешных кадров доказательством достоверного
   tableId/handId/seat actor и не включать реальные игровые действия
   без независимо подтверждённого источника и проверки результата.

## Ручная защищённая сборка

GitHub Actions -> `T050 Samsung live diagnostics — signed Code97` ->
`Run workflow` -> branch `feature/t043-gpt-decision-contract` ->
`Run workflow`. Это отдельный ручной workflow
`.github/workflows/t050-samsung-live-code97.yml` (также зарегистрирован
на основной ветке GitHub, чтобы появлялся в меню Actions).

Workflow доступен для запуска вручную, использует `android-signing`
и **ранее подтверждённый сертификат**. Проверяет сборку и unit-тесты,
верифицирует подпись, package id, monotonic `versionCode>=97`, и лишь
после успеха публикует artifact
`ai-remote-control-t050-live-code97`.
Если защищённые signing secrets недоступны, задача должна завершиться
ошибкой без публикации несовместимой APK.

В этом prototype workflow **реальные Android-16 instrumentation-тесты
не запускаются**. Оригинальный Samsung UI и сетевое взаимодействие
ChatGPT проверяются отдельно на устройстве. Не выдавать сборку
за полную рабочую автономную систему.

# T051 — как проверить действия ИИ-игрока на Samsung

## Что проверяется в этом этапе

Новый экран «T051 — ИСПЫТАТЬ ДЕЙСТВИЯ (БЕЗ 1WIN И СТАВОК)»
в операторском приложении. Это локальный Android-стенд, а не настоящий
покерный стол. Он проверяет:

1. T043GptDecisionContract.buildPrompt из синтетических карт Ah/Kd и
   искусственного, исключительно тестового состояния раздачи.
2. T043GptDecisionContract.review над заранее заданным тестовым JSON
   решения (НЕ ответ ChatGPT; не подтверждение реальной раздачи 1win).
3. Настоящий системный AccessibilityService.dispatchGesture по
   кнопке CHECK в самом приложении. Не используется View.performClick.
4. Отдельное подтверждение из обработчика OnClick тестовой кнопки.
5. Таймаут, STOP, отмену жеста и отсутствие Accessibility.
6. Живой журнал с причиной каждого отказа.

Этот этап НЕ доказывает реальное распознавание 1win, доступность GPT OAuth,
качество стратегии или исполнение ставок. Реальное игровое взаимодействие
остаётся заблокированным без независимой проверки состояния и эффекта.

## Порядок испытания на Samsung

- Установить подписанную тестовую APK после зелёного CI.
- В системных настройках включить Accessibility «AI Remote Control».
- В основном приложении включить STOP и остановить захват экрана.
- Открыть «T051 — ИСПЫТАТЬ ДЕЙСТВИЯ».
- ТЕСТ 1: допустимый CHECK; служба касается зелёной «CHECK · ЛАБОРАТОРНАЯ
  КНОПКА». Журнал отдельно отмечает системный жест и получение события
  приложением. PASS возможен только при наличии обоих подтверждений.
- ТЕСТ 2: RAISE при разрешённом только CHECK; контракт выдаёт NOT_LEGAL.
  Системного касания нет.
- ТЕСТ 3: CHECK с подавлением подтверждения тестовой кнопки; Android может
  завершить жест, но тест получает TIMEOUT. Повтора нет.
- STOP во время активного теста: старые результаты игнорируются.

Для 1win использовать существующий журнал наблюдения: выйти из лаборатории,
разрешить захват и включить диагностический overlay. При этом OCR не является
доказательством того, что можно выполнить игровой ход.

## Безопасность

Activity не экспортируется. Глобальный STOP обязан быть включён;
MediaProjection — выключен. Жест привязан к токену, геометрии видимой
собственной CHECK-кнопки и проверке активного пакета приложением Android.
Отмена или таймаут не инициируют повтор. Никаких API 1win, удалённых
координат, переводов или отправки данных игроков.

Следующие этапы: реальный OAuth GPT, точность OCR на устройстве, достоверный
источник текущей раздачи и подтверждение результата игрового действия.

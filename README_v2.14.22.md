# AI Remote Control GPT v2.14.22 — независимая покерная математика

**Исходники, не устанавливаемый APK.** Базовый неизменённый пакет: v2.14.21.

## Добавлено

- `PokerMath.kt` — чистый Kotlin без Android и сетевых вызовов. Строгие физические карты, исключение дублей, сильнейшая пятикарточная комбинация из 5–7 карт, проверка всех категорий, кикеров, ace-low wheel, full house из двух сетов, равенства и сравнений.
- Шансы банка `call / (pot_before_call + call)`, эффективные стеки, no-limit raise-to с отдельным обозначением короткого all-in; переполнение чисел отклоняется.
- Основной и побочные банки по вложенным фишкам, право победы только у не сбросивших карты, возврат неподтверждённого повышения и инвариант сохранения суммы фишек.
- Распределение банка при полностью известных руках на ривере с учётом ничьих. **Порядок получения нечётной фишки должен быть явно передан согласно местам относительно дилера**: модуль его не угадывает.
- Equity против **полностью известных** рук: точный перебор до установленного размера, иначе воспроизводимый Monte Carlo. Неизвестные диапазоны соперников пока не оцениваются. Число примеров и `exact`/`runouts` возвращаются отдельно.
- `VerifiedPokerMathBridge.kt` — только диагностический мост к достоверному состоянию раздачи: проверка эпохи, номера кадра, подтверждения идентичности стола/раздачи, фазы и количества карт; неизвестные числа оставлены `null`.
- Тесты на JVM, независимый Python-эталон из **552 наборов карт**, проверки некорректных данных и 7 JUnit-тестов для будущего CI Gradle.
- Службы касаний, разрешения, STOP и правила безопасного отказа не ослаблялись. Матмодуль **не создаёт игровые команды**.

## Запуск проверок

```bash
bash tools/run_jvm_tests.sh
python3 -m unittest discover -s tools -p 'test_*.py'
```

Эталон: `tools/fixtures/poker_oracle.tsv`. Генерация воспроизводима `python3 tools/generate_poker_oracle.py`. JVM-сценарии проверяют значения на эталоне **независимого** Python-алгоритма. Эти проверки не являются испытанием интерфейса 1win.

## Ограничения

- Не готова интеграция с реальным независимым идентификатором стола и раздачи; требование подтверждения не снято.
- Нет проверки подключённого OCR, мобильного распознавания карт, доступности игрового режима, автоматических действий или доступа к модели ChatGPT.
- Нет расчёта equity против *неизвестных* карт по диапазонам; Monte Carlo симулирует только неизвестные карты доски при **известных** картах соперников.
- Сервис Android SDK/Gradle APK не запускается в данном окружении. Присутствие JUnit-тестов не означает, что `testDebugUnitTest` уже запускался.

Полноценное APK — после завершения указанных этапов и проверки допустимости автоматизации в тестовом режиме.

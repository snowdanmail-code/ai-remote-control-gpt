# План после v2.14.25

## Выполнено в исходниках
- Медиа-захват, STOP, диагностический OCR, контроль поколения окна и актуальности кадра.
- Отдельный математический движок Texas Hold'em, память подтверждённых завершённых раздач и регистратор ошибок.
- v2.14.24: диагностическое сопоставление точных OCR-надписей с калиброванными местами.
- v2.14.25: read-only проверка правдоподобия изменения ставки, стека и очереди хода на трёх независимых кадрах; неполные доказательства не попадают в историю.

## Не готово
1. Нет проверенной калибровки оригинального интерфейса 1win: нужны реальные размеченные кадры нескольких стадий/анимаций/разрешений.
2. Нет независимого извлечения подтверждённых table ID, hand ID, opponent ID и нескольких полей состояния. Нельзя подделывать эти входы или брать ID игрока из одного кресла.
3. Нет доказанного канала перехода «действие соперника произошло» → `LiveOpponentAwareness` → подтверждённый конец раздачи → SQLite. Новая v2.14.25 — только диагностический контракт.
4. Не подтверждены авторизованный режим автоматизации платформы, реальное подключение ChatGPT и работа исполнительного контура на устройстве.
5. Не собраны/не установлены APK; Android unit/инструментальные и длительные испытания предстоят.

Следующий безопасный этап: отдельный offline annotation/replay dataset и проверка точности распознавания против независимой ручной разметки, затем source adapter без обхода STOP.

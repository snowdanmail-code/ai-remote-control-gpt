# AI Remote Control GPT v2.14.28 — Virtual-Chip Local Decision Strategy

**Исходники, не APK.** Целевая среда: оригинальное Android-приложение 1win в описанном оператором режиме **виртуальных фишек без пополнения и вывода денег**. Символ `$` — формат отображения счётчика игровых фишек, а не основание считать режим денежным. Режим не подтверждён технически самой программой; права на автоматизацию сторонней платформы отдельно не проверены.

## Что изменено относительно v2.14.27

1. `VerifiedLocalPokerStrategy.kt`: введена выполняемая локально стратегия, реализующая `AutonomousStrategy`. Она может выдавать `CHECK`, `CALL`, `FOLD`, `BET` и `RAISE` по проверенному состоянию и эквити, но **не взаимодействует с AccessibilityService напрямую**. Принципы: не выдавать оплачиваемое действие без достоверной оценки; сверять pot odds; для ставки/рейза требовать уже выбранную и независимо проверенную сумму в пределах min/max.
2. `FrameBoundEquity`: проверка hand/turn/captureEpoch/frameSequence, ограничений 0..1 и минимального числа моделирований. Для **точного полного перебора** допускается малое число исходов. Оценка не синтезируется из отсутствующих карт соперников.
3. `AutonomousObservation`: опциональные поля `equityEvidence`, `minVerifiedBetChips`, `maxVerifiedBetChips`. Старые источники и тесты совместимы благодаря значениям по умолчанию.
4. `AutonomousAndroidRuntime.ensureLocalStrategy()`: установка локального движка из `MainActivity.onCreate()`, если другой движок не подключён и активного контроллера нет. Установка НЕ снимает STOP, НЕ разрешает gestures и НЕ подменяет независимое подтверждение стола/раздачи.
5. Обновлена панель статуса до v2.14.28 и реальный индикатор наличия стратегии. API ChatGPT по-прежнему не подключён.
6. `versionCode=62`, обновлены имя артефакта ручного GitHub Actions и название экспорта отчёта.

## Что *не* готово

- Подтверждённая идентичность настоящего стола/раздачи, ID хода, набор активных кнопок, размеры ставок и источник проверенного equity **не подключены к живому OCR**. Поэтому **реальные игровые касания в 1win сейчас НЕ исполняются**. Из-за этого нельзя утверждать, что приложение уже самостоятельно играет.
- `LiveGamePermissionGate` остаётся закрытым до подтверждения разрешённого автоматизированного режима и фактического package name. Заявление о виртуальности фишек не является доказательством правил платформы.
- Нет API ChatGPT, подписка ChatGPT Plus не является сама по себе API-ключом. В этой версии локальный движок, а не ChatGPT как удалённый интеллект.
- Android Gradle-сборка, установка APK, длительный тест, реальные касания не проводились. Модульные проверки не заменяют такие испытания.

- `python -m unittest discover -s tools -p 'test_*.py' -q` — **217/217** пройдены.
- Добавлен отдельный исходный аудит отсутствия прямых касаний, проверки точной привязки equity, отказа от вымышленных данных и сохранения STOP.

## Следующий инженерный этап

Реальный frame-bound `AutonomousObservation` из нескольких подтверждённых кадров оригинального 1win с отдельными доказательствами идентификаторов, кнопок, активного хода и сумм; независимая проверка действия после нажатия; тестирование на устройстве и отчёт Incident Flight Recorder. Только затем можно проверять полноценный игровой цикл.

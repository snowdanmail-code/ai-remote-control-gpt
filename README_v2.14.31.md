# AI Remote Control GPT v2.14.31 — Hero Turn Lifecycle Diagnostics

**Только исходники; не Android APK.** Продолжение v2.14.30. Цель — диагностика начала/окончания видимого хода в оригинальном приложении 1win; не отдельная игра и не эмулятор.

## Изменения

- `HeroTurnLifecycleDiagnostics.kt`: чистый Kotlin/JVM-автомат визуальных состояний на основании кадров настоящей службы `MediaProjection` и независимой проверки корневого Android-окна.
- Последовательность: два кадра `WAITING/PREACTION` → два `READY` → `TURN_APPEARED_VISUAL` → `BET_SIZING` (если выбирается ставка) → два `WAITING/PREACTION` → `TURN_DISAPPEARED_VISUAL`.
- Однокадровые изменения не считаются началом или окончанием хода. Первоначально видимые `READY` без предыдущего наблюдения ожидания не объявляют новый ход.
- Отбрасываются повторные, переставленные и устаревшие кадры, смена источника, эпохи захвата или поколения окна, противоречия состояния кнопок и STOP. Для возвращения к диагностике требуется новая последовательность наблюдений.
- `CaptureService.kt`: результат формируется атомарно, вместе с существующими наблюдениями карт/цвета, после проверки активного окна.
- `FrameStore.kt`: хранит только текущий диагностический отчёт, стирает его при смене контекста, перекрытии стола, потере окна и STOP; история раздач в SQLite сохраняется.
- `MainActivity.kt`: отдельная кнопка для показа состояния визуального хода, без активации жестов.
- `versionCode=65`, `versionName=2.14.31-turn-lifecycle-diagnostics`; будущий workflow сборки обновлён.

## Ограничения

- Номер визуального эпизода **не является** идентификатором стола, раздачи или хода и не попадает в `AutonomousObservation`.
- Этот модуль **не делает** игрового решения, не включает `LiveGamePermissionGate` и не вызывает `dispatchGesture()`.
- Полная цепочка распознавание → стратегия → жест → подтверждение изменения игры пока не испытана на смартфоне.
- Реальные координаты дисплея, подтверждение стола и раздачи, допустимость ставок и защита от повторного действия остаются независимыми обязательными условиями.

## Проверки

Запуск JVM: `bash tools/run_jvm_tests.sh`. Отдельный новый набор — `HeroTurnLifecycleScenarios` (49 проверок: начало, ожидание, переход к ставке, окончание, STOP, окно, повтор и устаревание). Запуск Python: `python -m unittest discover -s tools -p 'test_*.py' -q`. Добавлены 2 Android Gradle/JUnit-теста в `HeroTurnLifecycleJvmTest.kt`, которые требуют будущего запуска через Android SDK/Gradle.

Для Android APK и тестирования установки нужны отдельные CI/устройство. Никаких утверждений о готовом APK или проверенной игре здесь нет.

# AI Remote Control GPT v2.14.21 — Incident Flight Recorder

Исходный код, НЕ APK. База: неизменённая версия v2.14.20.

В этой версии реализованы: локальный регистратор инцидентов `IncidentJournal`, безопасное циклическое сохранение событий в приватной памяти Android, отчёт `incident-report-v2.14.21.json` через системное сохранение документа, офлайн-анализатор отчёта `tools/analyze_incident_report.py` и проверка контрольного времени решения через `DecisionDeadlineGate`. Изменено логирование команд: запрос стратегии, отправка жеста Android и подтверждение действия игрой — разные события. У аварийного STOP теперь есть отдельный не блокирующийся на медленном расчёте стратегии сигнал отмены.

Отчёт включает тип ошибки, серьёзность, монотонную отметку времени, номер кадра/эпохи, задержку, выбранное действие, допустимые действия, известную фазу и числовые значения. Не содержит JPEG, OCR-текст, произвольные сообщения модели, логины, имена игроков, адреса, токены или ID столов и раздач. Журнал ограничен двумя локальными файлами по 160 КБ, экспортируются последние 400 событий. Любая ошибка самого регистратора не должна влиять на STOP.

Для анализа: `python3 tools/analyze_incident_report.py examples/synthetic_incident_report.json -o triage.md`. Пример — синтетический, он НЕ доказывает успех проверки в 1win. Реальный отчёт после будущего теста выбирает и сохраняет оператор из меню приложения, затем прикрепляет к чату самостоятельно. Сетевая отправка не реализована.

Локальные проверки: **577 Kotlin/JVM сценариев**, **168 Python тестов**. В том числе тесты модели, которая зависла во время решения, и сценария просроченного ответа.

**Не сделано:** Android Gradle/SDK, APK, установка на телефон, реальные действия и испытания в 1win, подключение стратегии ChatGPT, независимый источник идентичности стола/раздачи. Игровые касания остаются отключены до выполнения предварительных условий.

Полный перечень оставшихся компонентов и критерии готовности: `ROADMAP_v2.14.21.md`. История предыдущих версий сохранена в `README_RU.md`.
